Do NOT rush through phases by writing all code and committing.
This is a learning portfolio — the user needs to understand every line and concept to explain it in interviews.

**Why:** User explicitly said "what learning value am I getting if you do all the coding?" — the goal self-learning via repeated feedback loop, not task completion.

**How to apply:**
- Explain the concept BEFORE writing any code
- Break each phase into small, digestible steps
- Ask the user to try things themselves where possible
- Check understanding before moving forward
- Treat each phase as an interactive workshop, not a sprint
- Never bulk-create multiple files without explaining what each one does and why
- Let the user drive the pace
